# Project instructions

## Run the inventory app

From the project folder:

    python3 run.py

Open http://localhost:8000 and keep the server terminal open while using the page.

## Member workflow

Each member should work in the file or helper files assigned in README.md. Keep the short parent files and shared data fields in place; the app is already connected to them.

A positive movement quantity adds stock. A negative movement quantity removes stock. A product is low when its stock is at or below its threshold.
